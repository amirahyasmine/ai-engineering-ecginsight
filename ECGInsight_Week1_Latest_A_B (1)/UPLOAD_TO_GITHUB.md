1. Download and extract the ZIP. The files to upload are `README.md`, `.gitignore`, `docs/`, plus `data/`, `src/`, `notebooks/`, `evaluation/` and `prompts/` (each contains `.gitkeep`).
2. The three required files in `docs/` are `week1_observation_sheet.md`, `week1_system_map.png` and `week1_project_scope.md`.

4. On GitHub, select **Add file > Upload files**, upload content preserving relative folder names, and **Commit changes**. Replace README contents if already present.
5. Alternative via Mac Terminal:

```bash

cd ai-engineering-ecginsight
# Copy the extracted contents (except optional original_reports/) into this folder

```
